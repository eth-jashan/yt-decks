# Extension Icons

Place the following icon files in this directory:

- `icon-16.png` - 16x16 pixels (toolbar)
- `icon-48.png` - 48x48 pixels (extensions page)
- `icon-128.png` - 128x128 pixels (Chrome Web Store)

For development, you can create simple placeholder icons or use a tool like:
- https://favicon.io/
- Figma/Sketch with export

Icon should represent the YT Decks brand (purple theme, pad grid concept).
